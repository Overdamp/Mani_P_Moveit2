# คู่มือการใช้งาน Calibration Tool (`calibration_tool.py`)

โปรแกรมนี้เป็นเครื่องมือสำหรับตรวจสอบค่า **TF (Transform)** ระหว่างเฟรมต่างๆ ในระบบแบบ Real-time เพื่อใช้ในการ Calibrate หรือตรวจสอบความถูกต้องของตำแหน่งกล้องและ Tag

## 1. หน้าที่หลัก (Features)
โปรแกรมจะแสดงค่าพิกัด (XYZ) และระยะห่าง (Distance) ของคู่เฟรมต่อไปนี้:
1.  **Camera -> Shelf Tag**: กล้องมองเห็นป้ายชั้นวาง (Tag 11) อยู่ตรงไหน
2.  **Camera -> Cube Tag**: กล้องมองเห็นป้ายกล่อง (Tag 2) อยู่ตรงไหน
3.  **Shelf Tag -> Cube Tag**: ความสัมพันธ์ระหว่างชั้นวางกับกล่อง (คำนวณผ่าน TF Tree)

## 2. วิธีการรัน (How to Run)

### แบบปกติ (ใช้ค่า Default)
```bash
ros2 run mani_p_test calibration_tool.py
```
*   Camera Frame: `zed_left_camera_optical_frame`
*   Shelf Tag: `tag11`
*   Cube Tag: `tag2`

### แบบกำหนดเอง (Custom Frames)
หากต้องการเปลี่ยนชื่อเฟรม สามารถใส่ Argument ต่อท้ายได้ตามลำดับ:
```bash
ros2 run mani_p_test calibration_tool.py [camera_frame] [shelf_tag] [cube_tag]
```

**ตัวอย่าง:**
```bash
ros2 run mani_p_test calibration_tool.py zed_left_camera_frame tag5 tag0
```

## 3. การนำไปใช้ประโยชน์
*   **ตรวจสอบระยะ**: ดูว่า Tag อยู่ไกลจากกล้องแค่ไหน (ถ้าไกลเกิน 1-2 เมตร อาจจะคลาดเคลื่อนสูง)
*   **ตรวจสอบแกน**: ดูว่าค่า X, Y, Z เปลี่ยนแปลงตามที่คาดไว้หรือไม่เมื่อขยับหุ่นยนต์หรือวัตถุ
*   **หา Offset**: ใช้ค่าที่อ่านได้ไปใส่ในโค้ด (เช่น `shelf_action_server.py`) เพื่อกำหนดตำแหน่งเป้าหมายให้แม่นยำ

## 4. การประยุกต์ใช้เพื่อปรับแก้ URDF (URDF Calibration)
ท่านสามารถใช้เครื่องมือนี้ช่วยตรวจสอบความถูกต้องของไฟล์ URDF (โมเดลหุ่นยนต์) ได้ดังนี้:

### หลักการ
ค่าตำแหน่งของ Tag ที่เราเห็นในโปรแกรม (`Base_link -> Tag`) เกิดจากผลรวมของ 2 ส่วน:
1.  **URDF**: `Base_link -> Camera` (ค่าที่เรากำหนดในไฟล์ .xacro/.urdf)
2.  **Vision**: `Camera -> Tag` (ค่าที่กล้องอ่านได้จริง)

หาก **URDF ผิด** (เช่น กำหนดตำแหน่งกล้องห่างไป 5 ซม.) จะทำให้ตำแหน่งของ Tag ที่อ่านได้ **ผิดไป 5 ซม.** ด้วยเช่นกัน

### ขั้นตอนการตรวจสอบ
1.  **วาง Tag ที่ตำแหน่งที่รู้ค่าแน่นอน**:
    *   ใช้ตลับเมตรวัดระยะจากฐานหุ่นยนต์ (`Base_link`) ไปยัง Tag
    *   สมมติว่าวาง Tag ไว้ข้างหน้าหุ่นยนต์ระยะ **50 ซม.** (X = 0.50m)
2.  **รันโปรแกรมตรวจสอบ**:
    ```bash
    ros2 run mani_p_test calibration_tool.py Base_link tag11
    ```
    *(เปลี่ยน `tag11` เป็นชื่อ Tag ที่คุณใช้)*
3.  **เปรียบเทียบค่า**:
    *   ถ้าโปรแกรมอ่านได้ **X = 0.50m** (หรือใกล้เคียงมาก) -> **URDF ถูกต้อง** ✅
    *   ถ้าโปรแกรมอ่านได้ **X = 0.55m** -> แสดงว่าใน URDF เราอาจจะกำหนดตำแหน่งกล้อง **"ถอยหลัง"** มากเกินไป หรือ **"ยื่นหน้า"** น้อยเกินไป ทำให้ผลรวมระยะทางมันยืดออก
4.  **ปรับแก้**:
    *   กลับไปแก้ไฟล์ URDF (`.xacro`) ตรงส่วน `<joint>` ของกล้อง
    *   ขยับค่า `origin xyz="..."` ตามผลต่างที่พบ
