# ทฤษฎีและหลักการทำงานของ Approach Action Server (`approach_action_server.py`)

โปรแกรมนี้ทำหน้าที่สั่งให้แขนหุ่นยนต์เคลื่อนที่เข้าไปหา **AprilTag** ในระยะที่กำหนด โดยรักษาทิศทาง (Orientation) ให้เหมาะสมสำหรับการหยิบจับหรือทำงาน

## 1. หลักการพื้นฐาน (Core Concepts)

### 1.1 Relative Positioning (การระบุตำแหน่งสัมพัทธ์)
แทนที่จะระบุพิกัด $(x,y,z)$ แบบตายตัว โปรแกรมนี้ใช้การระบุตำแหน่ง **"เทียบกับป้าย Tag"** เช่น "อยู่ห่างจากป้าย Tag เบอร์ 11 เป็นระยะ 20 ซม." วิธีนี้ช่วยให้หุ่นยนต์ทำงานได้แม่นยำแม้ตำแหน่งของวัตถุจะคลาดเคลื่อนไปบ้าง ตราบใดที่กล้องยังมองเห็น Tag

### 1.2 MoveIt Constraints (ข้อจำกัดการเคลื่อนที่)
โปรแกรมนี้ใช้ฟีเจอร์ขั้นสูงของ MoveIt คือ **Constraints** แทนการระบุเป้าหมายแบบ Pose ธรรมดา:
*   **Position Constraint**: กำหนดให้ปลายแขน (End Effector) ต้องอยู่ในพื้นที่ทรงกลม (Sphere) ขนาดเล็ก ณ ระยะห่างที่กำหนดจาก Tag
*   **Orientation Constraint**: กำหนดให้ปลายแขนต้องหันหน้าเข้าหา Tag ในมุมที่ถูกต้อง (สามารถปรับ Roll Offset ได้)

## 2. ขั้นตอนการทำงาน (Workflow)

### Step 1: รับคำสั่ง (Goal Request)
*   **Tag Name**: ชื่อของ Tag ที่ต้องการเข้าหา (เช่น `tag11`)
*   **Distance**: ระยะห่างที่ต้องการหยุดก่อนถึง Tag (หน่วยเมตร)
*   **Roll Offset**: มุมหมุนเพิ่มเติม (ถ้าต้องการตะแคงหัวจับ)

### Step 2: สร้างข้อจำกัด (Define Constraints)
โปรแกรมจะสร้าง `MoveGroup.Goal` โดยระบุเงื่อนไขดังนี้:
1.  **Frame ID**: ระบุว่าเป็นเงื่อนไขเทียบกับเฟรมของ Tag นั้นๆ (เช่น `tag11`)
2.  **Position**: เป้าหมายคือจุดที่ห่างออกมาในแกน Z ของ Tag ตามค่า `distance`
3.  **Orientation**: คำนวณ Quaternion จากมุม Roll ที่ต้องการ เพื่อให้หัวจับขนานหรือทำมุมกับ Tag ตามต้องการ

### Step 3: วางแผนและสั่งการ (Plan & Execute)
*   ส่งเงื่อนไขเหล่านี้ไปให้ **MoveGroup**
*   MoveIt จะคำนวณ Inverse Kinematics (IK) เพื่อหาท่าทางของแขนที่ทำให้ปลายแขนเป็นไปตามเงื่อนไขที่กำหนด
*   หากหาทางได้ จะสั่งให้หุ่นยนต์เคลื่อนที่ไปทันที

## 3. จุดเด่น (Key Features)
*   **Dynamic Frame**: เป้าหมายผูกติดกับ Tag ถ้า Tag ขยับ (และ TF อัปเดตทัน) เป้าหมายก็จะขยับตาม
*   **Robustness**: การใช้ Constraints ช่วยให้ MoveIt มีอิสระในการจัดท่าทางของข้อต่ออื่นๆ มากกว่าการบังคับทุกแกนอย่างเคร่งครัด ทำให้หา Solution ได้ง่ายขึ้น
