# ทฤษฎีและหลักการทำงานของ Move Linear Action Server (`move_linear_action_server.py`)

โปรแกรมนี้ทำหน้าที่สั่งให้แขนหุ่นยนต์เคลื่อนที่ **"เป็นเส้นตรง"** ไปข้างหน้าหรือถอยหลัง ตามแนวแกน Z ของตัวหัวจับเอง (End-Effector Frame)

## 1. หลักการพื้นฐาน (Core Concepts)

### 1.1 Tool Frame Movement (การเคลื่อนที่ตามแนวแกนเครื่องมือ)
ปกติการสั่งหุ่นยนต์มักอ้างอิงแกนโลก (World Frame) เช่น "ไปทางขวา 10 ซม." แต่ในการทำงานจริง เช่น การเสียบปลั๊ก หรือการเจาะ เราต้องการสั่งว่า "เดินหน้าไปตามทิศที่หัวจับหันอยู่"
*   **Forward**: เคลื่อนที่ไปทาง +Z ของ `tcp_link`
*   **Backward**: เคลื่อนที่ไปทาง -Z ของ `tcp_link`

### 1.2 Vector Rotation (การหมุนเวกเตอร์)
เนื่องจาก MoveIt ต้องการพิกัดเป้าหมายในระบบ `Base_link` แต่เรามีเวกเตอร์การเคลื่อนที่ในระบบ `tcp_link` (เช่น $[0, 0, 0.1]$) เราจึงต้องใช้คณิตศาสตร์เรื่อง **Quaternion** มาช่วยหมุนเวกเตอร์นี้ให้เป็นทิศทางเดียวกันกับโลก

## 2. ขั้นตอนการทำงาน (Workflow)

### Step 1: รับคำสั่ง (Goal Request)
*   **Distance**: ระยะทางที่ต้องการเคลื่อนที่ (เมตร)
    *   ค่าบวก (+) = เดินหน้า
    *   ค่าลบ (-) = ถอยหลัง

### Step 2: คำนวณเป้าหมาย (Calculate Target)
1.  อ่านค่าพิกัดปัจจุบัน ($P_{current}$) และการหมุนปัจจุบัน ($Q_{current}$) ของหัวจับ
2.  สร้างเวกเตอร์การเคลื่อนที่ใน Local Frame: $V_{local} = [0, 0, \text{distance}]$
3.  หมุนเวกเตอร์นี้ด้วย $Q_{current}$ เพื่อให้ได้เวกเตอร์ใน Global Frame: $V_{global} = Q_{current} \times V_{local}$
4.  บวกเวกเตอร์นี้เข้ากับพิกัดปัจจุบัน: $P_{target} = P_{current} + V_{global}$

### Step 3: วางแผนเส้นทาง (Cartesian Path)
*   ส่งจุด $P_{target}$ ไปให้ MoveIt คำนวณ **Cartesian Path**
*   MoveIt จะสร้างเส้นทางที่เป็นเส้นตรงเป๊ะๆ ระหว่างจุดเริ่มต้นและจุดสิ้นสุด (ไม่ใช่แค่ไปให้ถึง แต่ระหว่างทางต้องตรงด้วย)

### Step 4: สั่งการ (Execute)
*   หากคำนวณเส้นทางได้สำเร็จ (ไม่มีการชน, ไม่เกินระยะเอื้อม) ก็จะสั่งให้หุ่นยนต์เคลื่อนที่

## 3. คณิตศาสตร์เบื้องหลัง (The Math)
สูตรการหมุนเวกเตอร์ $v$ ด้วย Quaternion $q$ คือ:
$$ v' = v + 2r \times (r \times v + w \cdot v) $$
(โดยที่ $r$ คือส่วน vector ของ quaternion และ $w$ คือส่วน scalar)
ในโค้ดมีการใช้สูตรสำเร็จรูปสำหรับการหมุนเวกเตอร์ $[0,0,z]$ เพื่อความรวดเร็วและแม่นยำ

## 4. ประโยชน์การใช้งาน (Use Cases)
*   **Insertion**: การเสียบของเข้าช่อง, การขันน็อต
*   **Approach/Retreat**: การเข้าหาวัตถุเพื่อหยิบ และการถอยออกมาหลังจากหยิบเสร็จ
*   **Precision**: การเคลื่อนที่ที่ต้องการความแม่นยำสูงในทิศทางที่กำหนด
