# ทฤษฎีและหลักการทำงานของ Move To Named Target Action Server (`move_to_named_target_action_server.py`)

โปรแกรมนี้ทำหน้าที่สั่งให้หุ่นยนต์เคลื่อนที่ไปยัง **"ท่าทางมาตรฐาน" (Named Targets)** ที่ถูกกำหนดไว้ล่วงหน้า เช่น ท่าเริ่มต้น (Home) หรือท่าเก็บแขน (Sleep) โดยระบุเพียงแค่ **"ชื่อ"** ของท่านั้นๆ

## 1. หลักการพื้นฐาน (Core Concepts)

### 1.1 Named Targets (ท่าทางที่ตั้งชื่อไว้)
ในการใช้งานหุ่นยนต์ เรามักจะมีท่าทางที่ใช้บ่อยๆ ซึ่งถูกกำหนดค่ามุมของข้อต่อ (Joint Values) เอาไว้ตายตัว เช่น:
*   **Home**: ท่าเตรียมพร้อม (Ready Pose) ที่แขนยืดออกเล็กน้อยพร้อมทำงาน
*   **Sleep**: ท่าพับเก็บแขน (Folded Pose) เพื่อประหยัดพื้นที่หรือพักมอเตอร์
แทนที่จะต้องจำค่ามุมของทุกข้อต่อ (J1, J2, J3, J4) เราสามารถเรียกใช้ผ่านชื่อเหล่านี้ได้เลย

### 1.2 Joint Space Planning
การเคลื่อนที่ระหว่างท่าทางมาตรฐานมักจะใช้การวางแผนแบบ **Joint Space**:
*   MoveIt จะคำนวณเส้นทางโดยดูที่การหมุนของแต่ละข้อต่อเป็นหลัก
*   ไม่สนใจว่าปลายแขนจะเคลื่อนที่เป็นเส้นตรงหรือไม่ (ต่างจาก Cartesian Path)
*   วิธีนี้ปลอดภัยและรวดเร็วสำหรับการเคลื่อนที่ระยะไกลๆ หรือการเปลี่ยนท่าทางหลัก

## 2. ขั้นตอนการทำงาน (Workflow)

### Step 1: รับคำสั่ง (Goal Request)
*   **Target Name**: ชื่อท่าที่ต้องการไป (String) เช่น `"home"`, `"sleep"`

### Step 2: แปลงชื่อเป็นค่ามุม (Lookup Joint Values)
โปรแกรมจะตรวจสอบชื่อที่ได้รับและแปลงเป็นค่ามุมของข้อต่อต่างๆ (Hardcoded หรือ Config):
*   **Home**: `J1, J2, J3, J4, J5, palm_joint` (Standard Pose)
*   **Sleep**: `J1, J2, J3, J4, J5, palm_joint` (Folded Pose)
*(หากไม่รู้จักชื่อ จะใช้ค่า Default เป็น Home)*

### Step 3: สร้างข้อจำกัด (Joint Constraints)
โปรแกรมสร้าง `MoveGroup.Goal` โดยระบุค่าเป้าหมายของทุกข้อต่อ (J1-J5 + Palm) พร้อมกำหนดค่าความคลาดเคลื่อน (Tolerance) ที่ยอมรับได้

### Step 4: สั่งการ (Execute)
*   ส่งคำสั่งไปที่ MoveGroup เพื่อวางแผนและสั่งให้หุ่นยนต์ขยับ
*   รอจนกว่าหุ่นยนต์จะไปถึงเป้าหมายและแจ้งผลลัพธ์กลับมา

## 3. ประโยชน์การใช้งาน (Use Cases)
*   **Reset/Recovery**: สั่งกลับท่า Home เมื่อจบงาน หรือเมื่อเกิดข้อผิดพลาด (Error Recovery)
*   **Initialization**: สั่งให้หุ่นยนต์ตื่นจากท่า Sleep มาเป็นท่า Ready ตอนเริ่มระบบ
*   **Safe Position**: สั่งให้หุ่นยนต์หลบไปอยู่ในท่าที่ปลอดภัยเมื่อไม่ได้ใช้งาน
